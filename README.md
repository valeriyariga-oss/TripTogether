# TripTogether
pet проект по разработке системы для совместного планирования поездок

TripTogether - сервис для планирования поездок, где можно подобрать билеты, трансферы и активности, а каждый участник может предложить свой вариант или проголосовать за другой. Все путешествия и информация о них синхронизируются в едином интерфейсе

## О проекте

Сервис решает задачу **согласованного планирования поездок для группы пользователей**, которые могут находиться в разных тайм-зонах и работать как онлайн, так и оффлайн. Система обеспечивает:

- Поиск и бронирование билетов/отелей/активностей через внешние API
- Совместное редактирование плана поездки
- Синхронизацию изменений в реальном времени
- Разрешение конфликтов при одновременном редактировании
- Работу в оффлайн-режиме с последующей синхронизацией
- Уведомления об изменениях, задержках и новых предложениях

## Моя роль

Как **Бизнес-системный аналитик** выполнила полный цикл работ от выявления требований до проектирования архитектуры и сценариев разрешения конфликтов.

## Ключевые вызовы, которые решались в проекте

- ✅ **Конфликты при совместном редактировании** — разработаны сценарии автоматического слияния и ручного разрешения
- ✅ **Оффлайн-режим** — спроектирована очередь операций и механизм синхронизации при восстановлении сети
- ✅ **Интеграция с внешними API** — выделен модуль интеграций с изоляцией сбоев
- ✅ **Разные тайм-зоны** — все даты хранятся в UTC с конвертацией на клиенте
