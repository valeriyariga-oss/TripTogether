# Frontend архитектура

## 1. Технологический стек

| Компонент | Технология | Назначение |
|-----------|------------|------------|
| **Язык** | TypeScript | Типизация, улучшение поддержки кода |
| **Фреймворк** | React 18+ | UI-компоненты |
| **Сборщик** | Vite | Быстрая сборка |
| **Управление состоянием** | Redux Toolkit / Zustand | Хранение глобального состояния |
| **Оффлайн-хранилище** | IndexedDB + Dexie.js | Локальное хранение данных |
| **Real-time** | Socket.io-client | Получение уведомлений |

---

## 2. Обоснование выбора

 **React**  обеспечивает компонентный подход, большая экосистема <br>
 **TypeScript**  - типизация уменьшает количество ошибок, улучшает читаемость <br>
 **Vite**  - мгновенный старт, быстрая сборка, современный подход <br>
 **Redux Toolkit / Zustand**: Redux Toolkit — стандарт для больших приложений, Zustand — лёгкая альтернатива <br>
 **IndexedDB + Dexie.js**  - единственная клиентская БД с поддержкой индексов и больших объёмов, Dexie упрощает работу <br>
 **Socket.io-client**  - единый транспорт с сервером, автоматическое переподключение <br>
