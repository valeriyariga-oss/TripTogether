# Модуль интеграций с внешними API

## 1. Назначение
Модуль отвечает за взаимодействие с внешними сервисами:
- Поиск авиабилетов
- Поиск отелей и жилья
- Поиск активностей и экскурсий
- (опционально) Погода, трансферы

## 2. Ключевые требования
- **Изоляция сбоев** — проблемы одного API не влияют на работу других модулей
- **Автоматическое восстановление** — переключение на резервные источники
- **Кэширование** — снижение нагрузки и ускорение ответов
- **Retry-механизм** — повтор при временных ошибках
- **Circuit Breaker** — отключение проблемного API на время
