# Backend архитектура

## 1. Общий обзор
Бэкенд спроектирован как **микросервисная архитектура** с выделением ключевых модулей для обеспечения масштабируемости, отказоустойчивости и удобства поддержки.

## 2. Технологический стек

| Компонент | Технология | Назначение |
|-----------|------------|------------|
| **Сервер приложения** | Node.js + TypeScript | Основная логика, API |
| **База данных** | PostgreSQL | Хранение пользовательских данных |
| **Кэш и сессии** | Redis | Кэширование, очереди, Pub/Sub |
| **Real-time** | Socket.io | Уведомления в реальном времени |
| **Очереди задач** | Bull (Redis) | Фоновая обработка (опционально для масштабирования)|

## 3. Обоснование выбора стека
**Node.js и TypeScript** обеспечивают высокую производительность, асинхронность, единый язык с фронтендом и строгую типизацию <br>
**PostgreSQL** обеспечивает надёжность, поддерживает JSON, транзакции и работает с тайм-зонами <br>
**Redis** наиболее подходящий вариант для кэширования и очередей <br>
Для функции real-time наиболее подходит **Socket.io**, который обеспечивает двустороннюю связь, автоматическое переподключение и поддержку комнат <br>
