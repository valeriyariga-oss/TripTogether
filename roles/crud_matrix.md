
# Права доступа CRUD

| Сущность | Роль | C | R | U | D | Условия доступа | Побочные эффекты | Уведомления |
|----------|------|---|---|---|---|-----------------|------------------|-------------|
| **User** | Owner | ✅ | ✅ | ✅ | ❌ | Полный доступ к своему профилю, чужие профили — только чтение | — | При изменении профиля |
| | Editor | ✅ | ✅ | ✅ | ❌ | Полный доступ к своему профилю, чужие профили — только чтение | — | При изменении профиля |
| | Viewer | ✅ | ✅ | ✅ | ❌ | Полный доступ к своему профилю, чужие профили — только чтение | — | При изменении профиля |
| | Admin | ✅ | ✅ | ✅ | ✅ | Полный доступ к любым профилям | При удалении профиля все связанные данные помечаются | Пользователю при блокировке/удалении |
| **Trip** | Owner | ✅ | ✅ | ✅ | ✅ | Полный доступ к своей поездке | При удалении поездки удаляются все связанные данные | Всем: "Поездка удалена" |
| | Editor | ❌ | ✅ | ❌ | ❌ | Только просмотр параметров поездки | — | — |
| | Viewer | ❌ | ✅ | ❌ | ❌ | Только просмотр | — | — |
| | Admin | ✅ | ✅ | ✅ | ✅ | Полный доступ ко всем поездкам | При удалении поездки все данные удаляются | Участникам, если админ удалил |
| **Participant** | Owner | ✅ | ✅ | ✅ | ✅ | Может приглашать, менять роли, исключать | При исключении участника его элементы остаются | Исключённому: "Вас удалили из поездки" |
| | Editor | ❌ | ✅ | ❌ | ❌ | Только просмотр списка участников | — | — |
| | Viewer | ❌ | ✅ | ❌ | ❌ | Только просмотр | — | — |
| | Admin | ✅ | ✅ | ✅ | ✅ | Полный доступ | Может добавлять/удалять кого угодно | Участнику, если админ добавил/удалил |
| **PlanItem** | Owner | ✅ | ✅ | ✅ | ✅ | Полный доступ ко всем элементам в своей поездке | При удалении элемента связанные альтернативы удаляются | Всем: "Элемент добавлен/изменён/удалён" |
| | Editor | ✅ | ✅ | ✅ | (✅) | **C/R/U**: любые элементы; **D**: только свои | При удалении своего элемента альтернативы по нему удаляются | Всем: "Элемент добавлен/изменён" (свои), "Элемент изменён" (чужие) |
| | Viewer | ❌ | ✅ | ❌ | ❌ | Только просмотр | — | — |
| | Admin | ✅ | ✅ | ✅ | ✅ | Полный доступ ко всем элементам | Может удалять любые элементы | Всем, если админ изменил/удалил |
| **AlternativeGroup** | Owner | (✅) | ✅ | ✅ | ✅ | Создаётся автоматически при конфликте или вручную | При выборе варианта остальные альтернативы архивируются | Всем: "Выбран итоговый вариант" |
| | Editor | (✅) | ✅ | ✅ | ❌ | Может предлагать альтернативы, но не удалять группу | — | Всем: "Новая альтернатива" |
| | Viewer | ❌ | ✅ | ❌ | ❌ | Только просмотр | — | — |
| | Admin | ✅ | ✅ | ✅ | ✅ | Полный доступ | Может удалять/редактировать любые группы | — |
| **Conflict** | Owner | ❌ | ✅ | ✅ | ❌ | Создаётся автоматически, Owner участвует в разрешении | При разрешении создаётся итоговый элемент | Участникам: "Конфликт разрешён" |
| | Editor | ❌ | ✅ | ✅ | ❌ | Может видеть и разрешать конфликты, в которых участвовал | — | Участникам о конфликте |
| | Viewer | ❌ | ❌ | ❌ | ❌ | Не видит конфликты | — | — |
| | Admin | ❌ | ✅ | ✅ | ✅ | Может просматривать и удалять конфликты | При удалении конфликта данные не восстанавливаются | — |
| **Notification** | Owner | ❌ | ✅ | ✅ | ❌ | Может отметить как прочитанное, но не удалить | — | — |
| | Editor | ❌ | ✅ | ✅ | ❌ | То же | — | — |
| | Viewer | ❌ | ✅ | ✅ | ❌ | То же | — | — |
| | Admin | ❌ | ✅ | ✅ | ✅ | Может удалять уведомления (например, старые) | — | — |
